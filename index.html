Privacy Policy

Gamepadmouse (hereinafter referred to as "the App") values your privacy and complies with relevant laws and regulations.

1. Items and Purpose of Collection

The App does not transmit or share your personal information to external servers. The App uses only the necessary functions for the following purposes:

  • Use of Accessibility Service: The App uses the Accessibility Service to convert gamepad input into screen touches, clicks, and scrolls. This permission is essential for core functionality.
  • Usage Data: Processes gamepad button inputs and stick movement information.
  • Purpose of Processing: Displaying a virtual mouse cursor and performing screen operations (click, drag, scroll).
  • Data Retention: No data is stored or transmitted externally; it is discarded immediately after the action is performed.
  • Settings Storage: User settings such as mouse speed and pointer size are stored locally on the device's SharedPreferences.

2. Provision of Personal Information to Third Parties

The App does not provide or disclose your personal information to third parties.

3. Period of Processing and Retention

The App does not store personal information on a server, so it does not retain it. Settings stored on the device are deleted when the App is uninstalled.

4. Special Notice on Accessibility API

The App uses the Accessibility API to perform the following actions:

  • Simulating screen touches and gestures (mouse operation via gamepad).
  • Displaying a mouse cursor image and black screen layer over the screen.

IMPORTANT: The App does not collect or share personal or sensitive data through the Accessibility API. It only provides convenience for UI manipulation using a gamepad.

개인정보처리방침 (Korean)

Gamepadmouse 앱(이하 "본 앱")은 사용자의 개인정보를 소중하게 생각하며, '개인정보 보호법' 등 관련 법령을 준수합니다.

1. 수집하는 개인정보의 항목 및 목적

본 앱은 사용자의 개인정보를 서버로 전송하거나 외부에 공유하지 않습니다. 본 앱은 다음과 같은 목적으로 필요한 기능만을 사용합니다.

  • 접근성 서비스(Accessibility Service) 이용: 본 앱은 게임패드 입력을 화면 터치, 클릭, 스크롤 등의 동작으로 변환하기 위해 접근성 서비스를 사용합니다. 이는 앱의 핵심 기능을 수행하기 위한 필수적인 권한입니다.
  • 사용 데이터: 게임패드의 버튼 입력 및 스틱 움직임 정보를 처리합니다.
  • 처리 목적: 가상 마우스 커서 표시 및 화면 조작(클릭, 드래그, 스크롤) 수행.
  • 데이터 보관: 어떠한 데이터도 저장하거나 외부로 전송하지 않으며, 동작 수행 후 즉시 폐기됩니다.
  • 설정값 저장: 사용자가 설정한 마우스 속도, 포인터 크기 등은 기기 내의 SharedPreferences에 로컬로 저장됩니다.

2. 개인정보의 제3자 제공

본 앱은 사용자의 개인정보를 제3자에게 제공하거나 외부에 공개하지 않습니다.

3. 개인정보의 처리 및 보유 기간

본 앱은 개인정보를 서버에 저장하지 않으므로 보유하지 않습니다. 기기에 저장된 설정값은 앱 삭제 시 함께 삭제됩니다.

4. 접근성 API(Accessibility API)에 대한 특별 고지

본 앱은 접근성 API를 사용하여 다음과 같은 동작을 수행합니다.

  • 사용자의 화면 터치 및 제스처 시뮬레이션 (게임패드 입력을 통한 마우스 조작).
  • 화면 위에 마우스 커서 이미지 및 블랙 스크린 레이어 표시.

중요: 본 앱은 접근성 API를 통해 사용자의 개인적이고 민감한 데이터를 수집하거나 공유하지 않습니다. 오직 게임패드를 이용한 UI 조작 편의성만을 제공합니다.
